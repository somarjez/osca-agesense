# K=4 UI/UX Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update every hardcoded K=3 reference in the frontend so the system displays 4 clusters, using the authoritative notebook color palette, with correct grid layouts, chart datasets, filter dropdowns, and help text.

**Architecture:** The changes are purely presentational — no DB schema or API changes. Color tokens flow from `tailwind.config.js` → `app.css` → `app.js` → Blade templates. PHP color helpers in `ClusterAnalyticsService.php` and `ClusterAnalysis.php` feed chart datasets. All cluster loops in Blade become `[1,2,3,4]`. Assets are rebuilt with `npm run build` after all edits.

**Tech Stack:** Laravel Blade, Livewire, Tailwind CSS, Chart.js, Alpine.js.
